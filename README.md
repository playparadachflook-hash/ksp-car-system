# ระบบขอใช้รถยนต์ออนไลน์ โรงพยาบาลโคกศรีสุพรรณ (KSP Car System)

โปรเจคปรับปรุงและพัฒนาใหม่ด้วย **Node.js + Express + SQLite (better-sqlite3)** จากระบบขอใช้รถยนต์เดิม (`carsystem` PHP/MySQL) โดยคงความสามารถเดิมทั้งหมด รองรับการเพิ่ม/แก้ไข/ลบข้อมูลใหม่ ปฏิทินขอใช้รถ สร้างเอกสาร PDF ขนาด A4 และมีสคริปต์โอนย้ายข้อมูลเก่าจากฐานข้อมูล MySQL เดิมให้ใช้งานร่วมกับระบบใหม่ได้อย่างสมบูรณ์

## การติดตั้งและใช้งาน
```bash
npm install
cp .env.example .env
# โอนย้ายข้อมูลเก่าจากฐานข้อมูล MySQL เดิม (แปลงรหัสภาษาไทย TIS-620/UTF-8 อัตโนมัติ)
npm run migrate
# เริ่มทำงานเซิร์ฟเวอร์
npm start
```

เปิดใช้งานได้ที่ `http://localhost:3531`
